# Calculator with plugins (C++)

Консольный калькулятор с поддержкой динамически загружаемых плагинов 

## Ключевые особенности
* Вычисление выражений с операторами `+`, `-`, `*`, `/` и скобками.
* Динамическая архитектура: подгрузка функций из DLL/SO файлов в папке `./plugins`.
* Независимость ядра от плагинов (использование C-ABI).
* Управление плагинами во время выполнения (команды `:load` и `:unload`).
* Имя функции определяется из кода библиотеки, а не из названия файла.
* Безопасная обработка исключительных ситуаций и ошибок области определения (Domain Error).
* Автоматический сборщик на базе CMake.

## Доступные на данный момент плагины
* Натуральный логарифм `ln()`.
* Экспонента `exp()`.
* Косинус `cos()`.
* Синус `sin()`.

## Как собрать
Для сборки требуется **CMake** (версия 3.20+) и компилятор с поддержкой **C++17**.

```bash
cmake -S . -B build
cmake --build build --config Release
cd build/Release  # (или build/Debug в зависимости от конфигурации)
./calc.exe        # на Linux: ./calc
